# 닥터마크(Dr.Mark) 온라인 광고 집행 킷 — 구글·네이버·메타

작성일: 2026-09-17
목적: 광고 계정에 그대로 복사해 넣을 수 있는 캠페인 구조·키워드·문안·예산·세팅 순서 제공
랜딩: 쿠팡 '닥터마크' 상품 페이지 (리뷰·로켓 배지가 전환 설득을 대신함)

---

## 0. 시작 전 준비물 (30분)

1. **쿠팡 파트너스 가입** (partners.coupang.com) → 내 상품의 파트너스 링크 생성
   - 외부 광고 → 쿠팡 랜딩은 자사 사이트가 아니라서 전환 픽셀을 못 심는다. 파트너스 링크의 클릭·전환 리포트가 유일한 성과 측정 수단.
   - 채널별로 서브ID를 다르게 발급: `google_s`(구글 검색), `naver_pl`(파워링크), `meta_v1`(메타) → 어느 채널이 팔았는지 구분 가능.
2. **광고 계정 개설**: 네이버 검색광고(searchad.naver.com), 구글 애즈(ads.google.com), 메타 광고관리자.
3. **브랜드 로고·제품 컷 10장, 사용 장면 영상 15~30초 2편** (숏폼 제작 역량 활용).

## 1. 전체 예산 설계 (월 150만 원 기준 — 비율로 조정 가능)

| 채널 | 월예산 | 역할 | 성과 판단 시점 |
|---|---|---|---|
| 네이버 파워링크 | 45만 (30%) | 구매 직전 검색 수요 수확 | 2주 |
| 구글 검색 | 30만 (20%) | 브랜드·정보성 검색 수확 | 2주 |
| 메타(인스타/페북) | 60만 (40%) | 수요 창출, 숏폼 소재 증폭 | 4주 |
| 네이버 GFA(배너) | 15만 (10%) | 리타깃·인지 보조 | 4주 |

- 첫 달은 "테스트 달": 채널별 클릭당비용(CPC)과 파트너스 전환 데이터를 모으는 것이 목표.
- 2개월차부터 파트너스 리포트 기준 전환 단가가 낮은 채널에 예산 70%를 몰아준다.

## 2. 네이버 검색광고 (파워링크) — 최우선 집행

### 2-1. 캠페인 구조
```
캠페인: 닥터마크_파워링크
 ├─ 광고그룹1: 브랜드 (입찰 100~200원, 상시)
 │   키워드: 닥터마크, 닥터마크 후기, 닥터마크 쿠팡, 드마크
 ├─ 광고그룹2: 핵심 카테고리 (입찰 300~800원에서 시작)
 │   키워드: [상품 카테고리 대표 키워드 5~10개 — 쿠팡 광고 키워드 리포트에서
 │           실제 매출 발생한 키워드를 그대로 가져올 것]
 └─ 광고그룹3: 롱테일/비교형 (입찰 200~400원)
     키워드: ○○ 추천, ○○ 순위, ○○ 가성비, ○○ 선물 등 조합형
```

### 2-2. 광고 문안 (제목 15자 / 설명 45자 제한)
| 구분 | 제목 | 설명 |
|---|---|---|
| A(신뢰형) | 닥터마크 공식판매 | 믿고 쓰는 닥터마크. 쿠팡 로켓배송으로 내일 도착, 후기로 확인하세요 |
| B(혜택형) | 닥터마크 특가진행중 | 지금 쿠팡에서 와우할인+쿠폰 적용가로. 리뷰 보고 결정하세요 |
| C(문제해결형) | ○○ 고민엔 닥터마크 | 싼 제품에 실패해봤다면. 성분과 인증으로 증명하는 닥터마크 |
- A/B를 동시 등록해 2주 후 클릭률 낮은 쪽 교체.

### 2-3. 운영 룰
- 브랜드 그룹은 무조건 1위 입찰 유지(경쟁사 선점 차단, 비용 미미).
- 카테고리 키워드는 2~3위 노출 목표(1위 입찰은 CPC 과열). 
- 주 1회: 노출만 있고 클릭·전환 없는 키워드 OFF, 전환 키워드 입찰 +10%.

## 3. 구글 광고 (검색 캠페인)

### 3-1. 캠페인 설정값
- 유형: 검색 / 목표: 웹사이트 트래픽 / 위치: 대한민국 / 언어: 한국어
- 입찰: 시작은 "클릭수 최대화" + 최대 CPC 한도 500원 → 데이터 쌓이면 전환 기반 전환
- 일예산: 10,000원

### 3-2. 광고그룹·키워드
```
그룹1 브랜드: [닥터마크], "닥터마크 후기", "닥터마크 쿠팡"  (완전일치·구문일치)
그룹2 카테고리: 쿠팡 매출 키워드 5~10개 (구문일치로 시작)
제외 키워드: 상표, 특허, 출원, 변리사  ← 동명 상표서비스(drmark.co.kr) 트래픽 오염 차단. 필수!
```

### 3-3. 반응형 검색광고 문안 (제목 최대 30자·한글 약 15자, 설명 90자·한글 약 45자)
- 제목 후보(7개 이상 입력): `닥터마크 공식 스토어` / `쿠팡 로켓배송 내일 도착` / `후기로 검증된 닥터마크` / `지금 와우할인 특가` / `성분으로 증명합니다` / `○○ 고민 해결` / `믿을 수 있는 선택`
- 설명 후보: `가격만 싼 제품에 실패해보셨나요? 닥터마크는 성분과 인증으로 증명합니다.` / `쿠팡 구매평 직접 확인하고 결정하세요. 로켓배송으로 빠르게 받아보세요.`

## 4. 메타 (인스타그램/페이스북) — 수요 창출의 메인 엔진

### 4-1. 캠페인 구조
```
캠페인: 닥터마크_전환(트래픽 최적화, 일예산 2만)
 ├─ 광고세트1: 관심사 타깃 (카테고리 관련 관심사 + 연령대는 제품에 맞게)
 ├─ 광고세트2: 유사 타깃 (인스타 계정 참여자 기반 — 계정 운영 4주 후 생성)
 └─ 각 세트에 소재 3종 A/B/C 동시 테스트
```

### 4-2. 소재 기획 (15~30초 세로 영상, 대표님 제작 역량 활용)
| 소재 | 훅(첫 3초) | 본문 구성 | CTA |
|---|---|---|---|
| A 비교실험형 | "일반 제품이랑 뭐가 다른지 직접 비교해봄" | 나란히 비교 → 차이 클로즈업 | "쿠팡에서 닥터마크 검색" |
| B 후기형 | "쿠팡 평점 4.○ 리뷰 ○○개, 이유가 있음" | 실제 리뷰 캡처 3장 + 사용 장면 | "리뷰 직접 확인하기" |
| C 문제공감형 | "이런 경험 있으면 3초만 보세요" | 불편 상황 재연 → 해결 장면 | "지금 특가 확인" |
- 성과 판단: 3초 조회율 30%↑ & 링크 클릭률(CTR) 1%↑ 소재만 생존, 나머지는 매주 교체.
- 자연 도달용으로 릴스에 먼저 올려 반응 좋은 것만 광고로 증폭(소재비 절약).

### 4-3. 주의
- 효능 보장·비포애프터 과장 표현은 메타 심의 거절 + 표시광고법 리스크. "치료·완치·의사추천" 문구 금지.

## 5. 네이버 GFA (성과형 디스플레이) — 보조 채널

- 시작 시점: 파워링크·메타가 안정된 후(2개월차).
- 소재: 메타에서 검증된 이미지·영상 재활용.
- 타깃: 카테고리 관심사 + 최근 쇼핑 행동 타깃. 일예산 5,000원 소액 테스트.

## 6. 측정 체계 (외부광고 → 쿠팡 랜딩의 한계 극복)

| 수단 | 무엇을 알 수 있나 |
|---|---|
| 파트너스 서브ID 리포트 | 채널별 클릭 → 주문 전환, 수익 |
| 쿠팡 윙 매출 추이 | 광고 시작 전 4주 vs 후 4주 총매출 증분 |
| 브랜드 검색량(네이버 데이터랩) | "닥터마크" 검색량 상승 = 인지도 광고 효과 |
- 주간 리포트 양식: 채널 / 비용 / 클릭 / 파트너스 주문 / 주문당 비용(CPA) / 다음 주 액션 — 5줄이면 충분.
- 손익 기준: `주문당 비용 < 상품 마진 × 0.7` 이면 증액, 넘으면 소재·키워드 교체.

## 8. 리스크 메모

1. **상표 미확인 상태에서 브랜드 광고 확대 금지**: 키프리스에서 우리 카테고리 '닥터마크' 등록 확인/출원이 선행돼야 함. 타인이 선등록한 상표라면 브랜드 키워드 광고가 분쟁 소지가 됨.
2. 구글에서 "닥터마크" 검색 시 상표출원 서비스가 상위 노출 중 → 제외 키워드(§3-2)와 함께, 자체 블로그·SNS로 브랜드 검색 결과 선점 병행.
3. 광고 문안의 효능·최상급 표현("최고", "1위", "치료") 금지 — 매체 심의 거절과 표시광고법 제재 모두 해당.
